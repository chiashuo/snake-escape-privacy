廣告服務可能處理裝置識別碼，或透過 IP 位址推估大略位置，詳見「廣告與第三方服務」。若你主動寄信聯絡，我們也會收到你提供的聯絡資料，詳見「聯絡方式」。

2. 資料的保存、安全與刪除

遊戲進度與設定保存在 Android 提供給本 App 的儲存空間，並由作業系統的應用程式存取限制保護。資料會隨遊戲進行更新，並保留供下次開啟使用。

刪除裝置上的遊戲資料

你可以前往 Android「設定 → 應用程式 → 蛇出來了 → 儲存空間」，選擇「清除資料」或「清除儲存空間」。實際選項名稱依裝置而異。這會重設關卡進度、已解鎖蛇皮與設定。

解除安裝通常也會移除本機 App 資料。App 沒有玩家帳號，因此沒有另外的遊戲帳號刪除程序。

Android 系統備份與裝置移轉

依你的裝置、Android 版本及備份設定，系統可能將遊戲資料納入雲端備份或裝置移轉，並在重新安裝或換機時還原。這些副本由系統或備份服務管理，開發者無法透過本 App 存取或代為刪除。

若要管理備份副本，請使用裝置或備份服務提供的設定。清除本機資料不代表既有的備份副本也已刪除。

3. 廣告、資料分享與第三方服務

預計上架版本會使用 Google 提供的 AdMob 服務顯示廣告，例如觀看後取得提示、生命或蛇皮的獎勵廣告。實際啟用此服務時，Google Mobile Ads SDK 會依 SDK 版本、裝置設定及同意狀態蒐集並分享廣告相關資料。

AdMob 處理的資料

依 Google 的 SDK 資料揭露說明，資料類型包含：

  • IP 位址：也可能用於推估裝置的大略位置。
  • 互動資訊：例如 App 啟動、點擊與影片觀看等互動。
  • 診斷資訊：例如啟動時間、應用程式停滯情形與能源使用等效能資料。
  • 裝置或帳戶相關識別資訊：例如可用的 Android 廣告識別碼、App Set ID，以及適用情況下與裝置上已登入帳戶相關的識別碼；可用範圍受設定與同意狀態影響。

這些資料用於提供廣告、衡量成效、分析及維護服務，以及防範詐騙與濫用。允許個人化廣告時，也可能用於顯示符合興趣的廣告。非個人化廣告仍可能使用部分資料來限制廣告顯示頻率、產生彙總報表或維護安全。

Google 表示 SDK 傳輸的資料會使用 TLS 加密。Google 對資料的保存期限、跨境處理與刪除方式依其隱私權政策及相關設定而定；資料可能在你所在國家或地區以外處理。清除遊戲存檔不會自動刪除 Google 已持有的廣告資料。

4. 你的隱私選擇

對於啟用正式廣告的版本，我們會依適用地區與規定提供必要的告知與同意流程。需要取得同意時，會先處理同意選擇，再請求相應廣告；需要提供修改或撤回選擇的入口時，會在 App 內提供廣告隱私選項。

你也可以使用 Android 或 Google 提供的廣告設定，管理廣告個人化或廣告識別碼。可用選項依裝置及版本而異，請參考 Google 設定說明。調整廣告設定不保證停止顯示所有廣告，也不代表所有資料處理都會停止。

如需查詢、更正或刪除我們持有的客服聯絡資料，或有其他隱私權請求，可以透過下方 Email 聯絡。我們會依適用規定處理，並在必要時確認請求者身分。由 Google 或備份服務持有的資料，亦可透過該服務提供的隱私權工具管理。

本頁為靜態說明頁面。我們未在本頁加入廣告、流量分析、追蹤像素、Cookie 或瀏覽器本機儲存功能。

詳見 GitHub Pages 資料處理說明與 GitHub 隱私權聲明。
